# 0002 流式边导出与 GUI 数据契约

- 日期：2026-11-11
- 状态：已接受
- 背景：L3 匹配器原先在 `match()` 结束后才一次性返回边列表，CLI 再整表覆盖写入 `l3_edges`。48k 文件规模下，中断会丢掉全部匹配结果；GUI 若各自重算指纹，报告与界面会出现两份不一致的分组真源。
- 决定：
  1. `match()` 增加 `edge_sink(a, b, ber)`，每条边首次确认即回调；`return_edges` 保留为兼容出口，两者内容一致。
  2. `Store.append_l3_edge()` 增量 upsert，同一对只保留更优（更小）BER；`l3` 默认不清空（中断续跑安全），`--reset-edges` 才清空重建。
  3. 分组统一由 `core/export.rebuild_groups()` 从既有索引＋已导出的边重建，`report` 与 GUI 都不重算指纹；无直连边的传递成员 BER 留 `None`，展示为「—」，不伪造数值。
  4. workdir 导出两个产物：`groups.json`（GUI 唯一数据源，含三层分组、文件元数据、边与疑似分级、可释放空间）与 `edges.csv`（人可读边清单，含所属组号）。CLI 新增 `export` 子命令，只导出不重算。
  5. GUI 为 `src/audio_dedup/gui/` 独立包，依赖方向 `gui → core → 标准库 / FFmpeg`，与 `cli → core` 平级，不反向依赖；GUI 只读 `groups.json`，隔离与恢复才经 `core.quarantine` 写盘。
- 后果：边数据与报告分组永远同源；换阈值后需显式 `--reset-edges`，否则旧边仍保留（更优值优先）。GUI 无 `groups.json` 时会从 `index.sqlite3` 现导一次，不触发任何音频解码。
- 补充决定（2026-11-11，处置粒度）：
  6. 处置提供四种粒度，全部收敛到同一个确认函数 `_run_quarantine()`：单文件（组内勾选）、整组／多组（分组列表多选＋全选）、整个文件夹（目录树节点）。四种粒度只决定「收集哪些路径」，不各自实现落盘逻辑。
  7. 目录筛选与批量处置按「路径前缀」判定（`_norm()` 统一 `\` 与大小写）。目录树在打开/刷新索引时一次性从 `groups_all` 构建并缓存每节点的组数／文件数，筛选过程不重建树。
  8. 批量安全阈值 `BULK_CONFIRM_THRESHOLD = 50`：达到即要求勾选「我已核对清单」才放行确认按钮。阈值只加二次确认，不改变「唯一的写动作是同盘 rename」这一约束。
  9. 筛选重建分组表后必须把选中标记钉回当前组所在行（`_sync_selection_after_fill`），否则「分组表显示 A 组、文件表显示 B 组」会造成误判处置对象。
- 补充决定（2026-11-11，波形与视觉）：
  10. 波形轨道数＝组内文件数（上限 `WAVE_TRACK_LIMIT = 60`，超出提示并只画前 60），不再固定 5 条。轨道高 34px、外层 `QScrollArea` 滚动；文件表与波形双向联动（选行→高亮并滚到该轨；点轨→选中该行；双击→从该处试听）。
  11. 波形使用真实峰值镜像包络填充（上沿 max、下沿 min、闭合成多边形）＋上包络描边，代替逐列竖线；同轨单色，只有活跃轨提亮，不用彩虹配色。
  12. 视觉口径对齐 SFX Tools 工业工作台：深灰阶底＋单一暖金 `#d9a441`；层级色改为灰阶递进（L1 近白／L2 中灰）且只有 L3 上色；数值与路径列用 Consolas；颜色只表达「需要人注意」，不做装饰。
- 复核时点：L3 全库跑通后，用真实边数复核 `groups.json` 与 `edges.csv` 的一致性；批量处置上线后需做一次「隔离 → 恢复」往返实测；波形联动需人类在桌面版实测。
