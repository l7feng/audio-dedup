# 0001 初始布局：Python src 布局 + 三层判定管线

- 日期：2026-11-09
- 状态：已接受
- 背景：新建独立音效库去重工具，需定仓内布局与版本真源。
- 决定：采用知识库 07 模板 03-Python源码卡（src 布局、tests 只经安装后包导入、pyproject 唯一依赖真源）；版本号唯一真源为 `VERSION` 文件，pyproject 经 hatchling 动态读取，包内 `__version__` 经 importlib.metadata 取安装版本；运行时无第三方 Python 依赖，FFmpeg 为外部子进程依赖；扫描索引等运行态由 CLI `--workdir` 指定到仓外。
- 后果：clone 后须 `build.ps1 setup` 建 venv 并安装才能跑测试；FFmpeg 缺失时 L2 不可用，须显式报错而非静默跳过。
- 复核时点：阶段三打包前复核目录白名单校验是否落地。
